# Three design directions and motion review

Requested after episode 03 feedback. Same title, five-step content, voice excerpt and animated Kodey, so typography and layout can be compared fairly. These are review outputs, not a selected final design.

- A: Editorial Blueprint — Inter, fine white grid, blue outline diagrams, subtitle reserved below content.
- B: Host-first Studio — Plus Jakarta Sans, warm neutral palette, larger Kodey and side panel, white subtitle card.
- C: Contrast Motion — Manrope, navy/cyan contrast, consistent line icons, dark subtitle lane.

All use 1080×1920. Subtitle lane starts at y=1570 with max two expected lines; footer remains below. All icons come from the same SVG family. Three type scales: title, body labels, subtitles.

Motion review: 12 seconds, four seconds per direction, same VO excerpt repeated per direction. Adds whole-character entry, lateral move, lean and light hop while existing blink/audio-driven mouth remain active. This does not add independently rigged arms or legs, and must not be presented as such.

Outputs: renders/design-review/design-A.png, design-B.png, design-C.png, comparison.png and motion-review.mp4. Three Google Fonts families are downloaded from their official google/fonts repository and stored with OFL licenses. Font loading is awaited before capture to avoid silent Arial fallback.
